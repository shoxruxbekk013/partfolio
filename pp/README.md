## 🚀 Getting Started Locally

### Prerequisites
- Node.js 18 or newer
- npm, yarn, or pnpm

### 1. Installation
Clone or extract the project archive, open a terminal in the folder, and run:
\`\`\`bash
npm install
\`\`\`

### 2. Development Server
Start the local Vite development server:
\`\`\`bash
npm run dev
\`\`\`
Visit [http://localhost:3000](http://localhost:3000) in your web browser.

### 3. Production Build
Create an optimized production bundle:
\`\`\`bash
npm run build
\`\`\`
The build output will be stored in the `dist/` directory, ready for deployment to Netlify, Vercel, or GitHub Pages.
